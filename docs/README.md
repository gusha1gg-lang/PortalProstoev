## Тесты
Тесты запускаются встроенным средством Django:

```bash
./.venv/bin/python manage.py test            # всё
./.venv/bin/python manage.py test apps.sla   # один модуль
```

Каждый модуль имеет свой `apps/<модуль>/tests.py`. Тесты также запускаются автоматически
при каждом push (GitHub Actions, см. `.github/workflows/tests.yml`).

## Быстрый демо-стенд
```bash
./.venv/bin/python manage.py seed_demo   # все демо-данные одной командой
```

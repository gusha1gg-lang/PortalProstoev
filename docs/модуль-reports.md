# Модуль: отчёты и дашборды (Этап 7)

Документ объясняет простыми словами, что показывает портал: главную страницу с
показателями, отчёт по SLA для заказчика и выгрузку данных в файл.

Модуль **ничего не считает сам** — все формулы (потери, доступность, MTTR/MTBF, штрафы)
берёт из модуля `sla` (`apps/sla/services.py`). Здесь только складываются результаты по
предприятиям и готовятся срезы. Благодаря этому дашборд, отчёт руководству и страница
`/sla/` всегда показывают одни и те же цифры.

## Страницы

| Адрес | Что это |
|---|---|
| `/` | **Дашборд** (главная): KPI, графики, срезы, список инцидентов |
| `/reports/sla/` | **SLA-отчёт для заказчика** — печатная страница «на отправку/PDF» |
| `/reports/export/` | Выгрузка инцидентов за период в **CSV** (открывается в Excel) |
| `/reports/chart-data/` | Данные графиков в JSON (для обновления без перезагрузки) |
| `/sla/` | Старый отчёт по потерям и SLA (модуль `sla`, Этап 5) |

Период задаётся на всех страницах: `?period=ГГГГ-ММ` (по умолчанию — текущий месяц),
предприятие — необязательным `?enterprise=<id>`.

## Показатели на дашборде (KPI)

| Показатель | Как считается |
|---|---|
| Инцидентов | Кейсы (по одному на кейс) + одиночные простои |
| Простои, ч | Сумма «чистого» времени инцидентов (мин → ч) |
| Потери, ₽ | По формулам модуля `sla`, по участкам без двойного счёта |
| Доступность, % | (время периода − простои) / время периода |
| MTTR, мин | простои / число инцидентов |
| MTBF, мин | (время периода − простои) / число инцидентов |
| Доля вины ИТ, % | простои вины ИТ / все простои (любая вина) |
| Штраф SLA, ₽ | По договорам предприятий (модуль `sla`) |

Учитываются только простои со статусом **«Подтверждён»/«Закрыт»** и виной **ИТ**.

## Графики

Рисуются библиотекой **Chart.js**, которая **лежит в проекте локально**
(`static/vendor/chart.umd.min.js`) — интернет в корпоративной сети не нужен.

1. Простои по месяцам (столбцы, часы) — 6 последних месяцев.
2. Потери по предприятиям (горизонтальные столбцы, ₽).
3. Топ причин (кольцевая диаграмма, минуты).

> Если библиотека почему-то не загрузилась, страница всё равно работает: графики просто
> не рисуются, а все цифры видны в таблицах ниже (см. проверку `typeof Chart` в шаблоне).

## Выгрузка в CSV

Файл отдаётся в кодировке UTF-8 с BOM и разделителем `;` — так Excel корректно открывает
русский текст. Колонки: Период, Предприятие, Тип, Дата, Название, Категория,
Длительность (мин), Потери (₽).

> Нужен ли именно `.xlsx` (библиотека `openpyxl`) — уточняется, см. `question.md`, В20.

## Устройство (папка `apps/reports/`)

| Файл | Что делает |
|---|---|
| `services.py` | Сборка KPI, срезов (по категориям, предприятиям, месяцам), строк для выгрузки |
| `views.py` | Страницы: дашборд, SLA-отчёт, экспорт CSV, JSON для графиков |
| `urls.py` | Маршруты модуля |
| `templates/reports/dashboard.html` | Дашборд: карточки, графики, таблицы |
| `templates/reports/sla_report.html` | Печатный SLA-отчёт |
| `tests.py` | Тесты KPI, срезов, страниц и выгрузки |

## Статика и оформление

- `static/css/portal.css` — стили портала (светлая тема, карточки, таблицы, стиль печати).
- `static/vendor/chart.umd.min.js` — локальная копия Chart.js.
- `templates/base.html` — общий «каркас» страницы с навигацией.
